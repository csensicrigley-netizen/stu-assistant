# 智能日历原生首版 · 1.1.0

这是完整 Android App 的本机验证版本，不是此前 HTML 演示，也不是通知能力探针。原有服务器、账号、课表迁移和五个主导航保留。APK 只在本机交付，不上传 GitHub，不自动发布线上下载或更新通道。

## 交互

- 事项首页一个「记一件事」入口，考试和成绩降为次级入口；本地事项与既有计划可查看、勾选完成。未经分类的学校内容称「课程动态」，不把每条动态冒充作业。
- 顶部输入框进入时自动聚焦并唤起键盘；更多菜单提供手动记录。提交后输入栏保持位置，提交按钮为 48dp 圆形，按下/松开分别反馈。输入区域使用大范围柔边 Backdrop 模糊；提交时由按钮中心用 1250ms 渐缓圆形蒙版展开页面，输入栏锚点不变；请求期间显示沿时间轴游走的光点。
- 固定标题「建议」，按钮「确认」。不显示「建议安排」、未保存状态、时间范围选择器、手势教学、底部待保存说明。
- 默认竖向三天视图，当前日居中，三列共用小时栏；中间视窗独立平移和缩放，上下边缘采用 Kyant Backdrop 的模糊、轻微形变色散与渐隐。已有课程、个人事项及旧计划来自真实设备缓存；不注入示例课程或模板事件。
- 日期左右切换采用有方向的 280ms 滑动；浏览日期不改事件。时间线支持平移、双指缩放；去掉「回到事项」「返回修改」，系统返回或顶部 × 回到输入并保留文字。当前事项可拖动，时间段两端改变时长；时间点与截止点有圆点/线命中区。普通时间点的空心尾柄可拉出时长，时间段下端收回可还原时间点。
- 长按空白或「时间 / 未安排」行可安排没有精确时间的事项；点事件才展开日期、时间的精确编辑。没有默认补一小时时长，不把只有日期的截止画成零点。
- 多事项独立选择、调整，一次确认原子保存。确认后首页定位到新事项日期。保留计划、截止、提醒等独立字段。

## 在线与本地边界

设备只在主动提交时请求 `https://stu-mcp.com/api/calendar/v2/mobile/parse`。这个入口使用已有 STU 登录身份，服务器验证固定来源 `https://stu.oyishi.asia/v1/me`，随后调用真实 Jev + Duckling。Jev Key 留在 gcp-stu-mcp；APK 中没有 Key 或共享签名密钥。POST 不自动重发，错误不填充模板。

新事项使用设备 Keystore 加密、AtomicFile 原子保存，按服务器和助手账号隔离。确认批次防重复，切换账号后拒绝旧页面写入。退出登录保留本地事项，删除账号删除对应本地事项。新事项不会调用旧 `/v1/plan` 云保存；旧计划仍能读取和完成，不偷偷删除或迁移。

新推理接口不创建服务器预览，不保存输入、输出或内容哈希。服务器仅保留受限访问元数据和既有用量统计，IP 准入和全局/用户用量治理与 Jev Key 路由分开。旧原型预览兼容接口未向 App 开放，历史数据本次不删除。

## 本版边界

- 提醒意图保留，但尚未接入设备通知调度；展开「事件选项」后明确显示通知未启用。默认仅显示建议、时间线和底部固定确认，已有的事项、备注、优先级及提醒配置在事件选项内原位编辑；不再展开长表单。
- MySTU 自动分类和「每条只分析一次」设置未在本次偷偷开启，课程动态不会后台上传。
- 现有课程、旧云计划作为只读时间线背景；当前识别批次可拖动修改。时间窗、日期截止保留其精度，用户可以主动添加准确安排。

## 验收

领域单元测试覆盖日期截止不变零点、点/段切换和独立字段保留。设备测试覆盖本地原子确认、重复确认、账号/服务器隔离、关闭恢复，以及真实线上提交、键盘、输入栏锚点、切日和拖动。

在线设备测试必须显式 `-e calendarOnline true`：使用独立偏好和目录、临时 STU 测试账号，结束删除测试账号；它会消耗真实 Jev 用量，普通测试不会自动运行。截图为合成测试内容，仅放本机 output，不提交用户数据。

1.1.2 补充：建议页无纵向滚动；时间编辑与字段编辑原位替换时间线。日期一行、开始与结束并列一行，相关时间值同时可见，不做标签切换；键盘和底部操作保持可见。玻璃按钮采样当前页面底色，输入环境模糊独立并在展开时退场，不采样被覆盖的首页。双指缩放统一接管事件与空白区域的触摸，视窗变化不重建监听器；从单指切为双指时撤销该手势临时事件位移。

数字动效按用户提供的 Number pop-in 改为常驻字符层，单次变化逐位柔化弹入；连续更新保持不透明与轻微模糊，停下后清晰落定。设备回归用画面像素检查快速更新不出现空白，而不只检查无障碍文本。

三天日历追加：整页固定，三列共用左侧小时栏及横向刻度；重叠安排并排，跨日段按日显示，移动保持时长。上下 56–96dp 柔化边缘采用两层渐进模糊、轻微透镜形变及色散，整个视窗内容在边缘平滑归零，不叠加矩形盖板，中心保持清晰；只采样日历自身。触感对应当前尺度的次刻度，限制频率并继承全局设置。参考项目与固定源码版本见 DESIGN.md。
