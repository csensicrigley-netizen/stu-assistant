# 智能日历原生首版 · 1.1.0

这是完整 Android App 的本机验证版本，不是此前 HTML 演示，也不是通知能力探针。原有服务器、账号、课表迁移和五个主导航保留。APK 只在本机交付，不上传 GitHub，不自动发布线上下载或更新通道。

## 交互

- 事项首页一个「记一件事」入口，考试和成绩降为次级入口；本地事项与既有计划可查看、勾选完成。未经分类的学校内容称「课程动态」，不把每条动态冒充作业。
- 顶部输入框进入时自动聚焦并唤起键盘；更多菜单提供手动记录。提交后输入栏保持位置，背景向完整页面展开；真实请求尚未完成时显示骨架。
- 固定标题「建议」，按钮「确认」。不显示「建议安排」、未保存状态、时间范围选择器、手势教学、底部待保存说明。
- 一行横向时间线贯穿左右屏幕，使用 Kyant Backdrop 模糊并羽化边缘。已有课程、个人事项及旧计划来自真实设备缓存；不注入示例课程或模板事件。
- 日期左右切换采用有方向的 280ms 滑动；浏览日期不改事件。时间线支持平移、双指缩放和回到事项。当前事项可拖动，时间段两端改变时长；时间点与截止点有圆点/线命中区。普通时间点的空心尾柄可拉出时长，时间段右端收回可还原时间点。
- 长按空白或「安排时间」可安排没有精确时间的事项；点事件才展开日期、时间的精确编辑。没有默认补一小时时长，不把只有日期的截止画成零点。
- 多事项独立选择、调整，一次确认原子保存。确认后首页定位到新事项日期。保留计划、截止、提醒等独立字段。

## 在线与本地边界

设备只在主动提交时请求 `https://stu-mcp.com/api/calendar/v2/mobile/parse`。这个入口使用已有 STU 登录身份，服务器验证固定来源 `https://your-domain.example.com/v1/me`，随后调用真实 Jev + Duckling。Jev Key 留在 gcp-stu-mcp；APK 中没有 Key 或共享签名密钥。POST 不自动重发，错误不填充模板。

新事项使用设备 Keystore 加密、AtomicFile 原子保存，按服务器和助手账号隔离。确认批次防重复，切换账号后拒绝旧页面写入。退出登录保留本地事项，删除账号删除对应本地事项。新事项不会调用旧 `/v1/plan` 云保存；旧计划仍能读取和完成，不偷偷删除或迁移。

新推理接口不创建服务器预览，不保存输入、输出或内容哈希。服务器仅保留受限访问元数据和既有用量统计，IP 准入和全局/用户用量治理与 Jev Key 路由分开。旧原型预览兼容接口未向 App 开放，历史数据本次不删除。

## 本版边界

- 提醒意图保留，但尚未接入设备通知调度；界面明确提示不会发送通知。
- MySTU 自动分类和「每条只分析一次」设置未在本次偷偷开启，课程动态不会后台上传。
- 现有课程、旧云计划作为只读时间线背景；当前识别批次可拖动修改。时间窗、日期截止保留其精度，用户可以主动添加准确安排。

## 验收

领域单元测试覆盖日期截止不变零点、点/段切换和独立字段保留。设备测试覆盖本地原子确认、重复确认、账号/服务器隔离、关闭恢复，以及真实线上提交、键盘、输入栏锚点、切日和拖动。

在线设备测试必须显式 `-e calendarOnline true`：使用独立偏好和目录、临时 STU 测试账号，结束删除测试账号；它会消耗真实 Jev 用量，普通测试不会自动运行。截图为合成测试内容，仅放本机 output，不提交用户数据。
