# Compose 触感分型与原强度恢复

版本：1.0.34-native.1（versionCode 35）。按用户本轮指示，取代上一版通过低倍率减轻反馈、仅保留两个机械按钮的规则。

## 力度与播放路径

- 所有按钮的两阶段、勾选、设置、普通选择和滑条试听均保持原 1.0 增益。`reject` 的第二脉冲同样为 1.0，不再乘 0.85。
- 唯一例外为底部五主导航：单次 `navigation` 为 0.8。UI 只传原全局强度，倍率只在引擎应用一次。按钮的 `navigate_press/release` 与此单次事件独立，仍为 1.0。
- 全部事件恢复 RichTap direct／SDK 优先，再降级到 Android primitive、可控幅度波形与系统效果。试听使用原单次锐度 100 参考；主提交保留原 52／100、完整轮廓及 110ms 间隔。
- 全局滑条仍为 0–100；0 立即停止。没有新增用户配置项，也不改变滑条连续 Float、松手保存／试听和取消恢复的交互。

## 液态玻璃按钮分型

| 类型 | 使用场景 | 按下／松开锐度 | 最小起振间隔 |
|---|---|---|---|
| Navigation | 开始、示例、返回、继续、跨页、外链、导入步骤 | 40／75 | 80ms |
| Submit | 登录注册、连接、同步、提交验证码、解析、保存导入、检查更新、重试 | 原 52／100 | 原 110ms |
| Utility | 更改、选文件、模板、复制、切周、展开、取消、打开表单、排序 | 70／90 | 110ms |
| Destructive | 清除已存密码、退出登录、最终删除、解除绑定 | 100／35 | 150ms |

锐度是 RichTap 协议相对参数，不是马达频率 Hz，也不等价于强度倍率。无对应设备能力时，通过 primitive 类型与短波形时长保留可实现的差异。按住超过间隔后松手立即释放，不强加额外等待。

所有应用 `LiquidButton` 收敛到 `NativeGlassButton`，`NButton` 与「我的」连接卡共用该适配。现有调用按用途显式声明，不读取动态按钮文案猜测行为；普通非玻璃行、图标按钮与分段容器不因此变成机械按钮。玻璃材质、圆角和按压形变沿用既有 Kyant 源码。

## 配对与结果反馈

一次按下锁定类型与全局强度，松开使用同一组参数；忙碌状态导致禁用时仍完成已接受配对，强度变为 0 则静音。交互 Release 与点击回调共用去重逻辑，业务回调销毁页面前提交释放请求。取消不补释放，不全局打断其他控件。

删除所有按钮成功／失败路径额外的 `confirm/reject` 触发，避免变成三次或四次反馈；结果继续用现有视觉状态展示。引擎保留单次语义 API 供非按钮场景使用。机械短尾不积压，快速或重叠请求仍受限频控制。请求计数不等于硬件实际起振次数。
