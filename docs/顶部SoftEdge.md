# 顶部 Soft Edge

2026-11-01：仅顶部，覆盖完整 App 的共用 NPage 和抽屉滚动区域。底部导航不增加 Soft Edge。

- 页面保持现有标题和布局，内容滚入状态栏附近时柔化；范围为状态栏高度加 44dp，最多视口高度的四分之一。使用较长的低强度尾部，不用短距离内突然变糊的过渡。
- 抽屉只处理固定标题及关闭按钮下方的 36dp 内容带，标题和按钮保持清晰。
- 效果强度随前 24dp 的滚动位移直接变化，返回顶部同步退出；无延迟动画，也没有滚动一像素就触发完整模糊的开关。
- Android 13+ 使用 RuntimeShader / RenderEffect 两轴密集高斯采样，采样范围由顶部 10dp 按 `(1-y/depth)^3` 降到零；较密采样避免高密度屏幕文字出现重复轮廓。过渡下端的斜率、曲率均归零，视口其余部分直接返回原始像素。GPU 读取当前内容层，不截屏、不定时采样。
- 内容接近极顶端时渐隐：透明度损失从顶端 88% 以三次曲线迅速减弱，半程仅 11%，末端归零。渐隐露出实际页面或玻璃抽屉底色，不在透明抽屉上绘制近似主题色块。低版本只保留该渐变。没有整页材质遮罩或底部模糊；没有改变触感和抽屉层级。

当前 Compose 为 1.12.0。官方渐进 blur API 要求 1.13.0-beta01，故本次采用平台 GPU 实现并保持现有依赖。今后升级稳定版可评估替换共用修饰符；尚未做真机性能或 iOS 像素一致性验收。

依据：[官方 blur 概述](https://developer.android.com/develop/ui/compose/graphics/blur/overview)、[滚动边缘示例](https://developer.android.com/develop/ui/compose/graphics/blur/examples)。用户截图作为视觉目标，未将截图里的 iOS API 名称作为 Android 实现依据。

这是产品 UI 改动，属于下一次完整 App 功能交付；本轮不修改机型探针的版本登记。GPU 像素回归检查顶部差异及正文、底部不受影响；原抽屉交互回归检查覆盖、退场和焦点保护。

验证（2026-11-01）：`assembleDebug`、`assembleDebugAndroidTest`、`lintDebug` 通过；API 37 模拟器的 GPU 像素测试和 8 项抽屉回归共 9 项通过。人工检查浅色、深色和滚动抽屉：固定标题及关闭按钮保持清晰，顶部内容渐隐时露出真实玻璃底色。低于 API 33 的渐隐降级和真机帧率尚未验证。顺带为 debug 网络配置显式补齐 `includeSubdomains="false"`，解决原有 lint 错误，不扩大允许明文访问的范围。
