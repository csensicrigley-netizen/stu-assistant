# 原生液态玻璃底栏实现说明（glass.2 历史记录）

本文保留首轮 `glass.2` 的实现与验证记录，其中的 Bitmap 桥已被移除。当前版本 `gpu.1` 使用原 WebView 实例经 `AndroidView + layerBackdrop` 接入 GPU 图层，最新架构、动画证据、性能限制与 APK 校验见 [WebView 实时 GPU 液态玻璃验证](WebView实时GPU液态玻璃验证.md)。

本轮将 Android App 的底部导航接入原生 Jetpack Compose 与 Kyant Backdrop。今天、计划、课表、学业、校园、我的六个目的地继续使用现有 React/WebView 页面；本轮没有把整个 App 迁移为 Compose。

底栏源码移植自 [Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass/tree/65ab177e90e5c1d8c62e70cf7755841982da65f6)，固定提交为 `65ab177e90e5c1d8c62e70cf7755841982da65f6`。六个文件是 `LiquidBottomTabs.kt`、`LiquidBottomTab.kt`、`DampedDragAnimation.kt`、`InteractiveHighlight.kt`、`DragGestureInspector.kt`、`Coroutines.kt`，位于 `web/android/app/src/main/java/com/stuassistant/app/glass/`。运行依赖固定为 Backdrop `2.0.1`、Shapes `1.2.1`。

源码映射、保留参数与本地适配详见 [UPSTREAM.md](../web/android/app/src/main/java/com/stuassistant/app/glass/UPSTREAM.md)。Apache 2.0 许可保存在同目录的 [LICENSE-AndroidLiquidGlass.txt](../web/android/app/src/main/java/com/stuassistant/app/glass/LICENSE-AndroidLiquidGlass.txt)，并通过 [assets/licenses/android-liquid-glass.txt](../web/android/app/src/main/assets/licenses/android-liquid-glass.txt) 随 APK 打包。

## 接入边界与材质来源

- `LiquidGlassNavigationPlugin.kt` 在现有 WebView 上方挂载 ComposeView，处理窗口安全区、页面状态、显示生命周期及背景采样。
- `LiquidGlassBottomBar.kt` 只负责 App 图标、中文标签、角标、主题与六个目的地的适配；模糊、折射、高光、拖拽物理保留在上游移植文件中。
- 上游控件保留普通背景与标签内容的组合采样、64 dp 容器和 56 dp 内部几何，以及拖拽、速度变形、松手吸附。减少动态时关闭相应形变和位移动画。
- 背景来自当前 WebView 导航区域的实际像素：在 UI 线程将该区域绘制到半分辨率 Bitmap，再由 Compose Image 提供独立背景源。背景源沿用上游透明采样层的顺序，只供玻璃读取，不把旧截图覆盖到页面。玻璃控件与背景源互为兄弟图层，避免将玻璃自身采入背景。
- 宿主在正常 84 dp 导航占位上方增加 20 dp 绘制空间，并相应增加顶部内边距，容纳上游快速拖动时的透镜形变；静止底栏的位置和网页占位保持一致。
- 原生宿主使用单独的透明主题，覆盖项目全局 `android:background=@color/paper`。ComposeView 自动创建的内部 AndroidComposeView 也必须继承透明背景，否则会以纯色挡住整个导航区域。透明设置不改变窗口和系统栏主题。
- 背景采样在交互期间按约 80 ms 间隔更新，滚动、换页、主题及布局变化会请求短时刷新；空闲后停止。原生动画由 Compose 驱动，采样间隔不代表已测得的动画帧率。键盘、网页模态弹层和后台状态会隐藏底栏并停止采样。

## 导航与触感规则

| 操作 | 路由与触感约定 |
| --- | --- |
| 普通按钮 | 保留原有按下、松开两段反馈，沿用强度调节及取消规则。 |
| 成功切换到另一底栏目的地 | 由原生宿主发出一次 `selection`，网页接收路由事件时不重播触感。 |
| 重选当前目的地 | 不振动；课表子页仍可借当前课表入口返回概览。 |
| 底栏取消拖动或未提交的手势 | 恢复已提交的选中位置，不导航、不振动。 |
| 强度设为 0 | 关闭触感。 |

原生选择、网页路由和硬件返回使用同一组目的地；快速反向选择通过基于前一状态的更新保留最后一次导航意图。Android 以原生 IME Insets 决定键盘隐藏，网页视口推断提供初始补充。

网页/PWA 继续使用 Web 导航。Android 只有收到原生挂载确认后才隐藏 Web 底栏；插件不可用或挂载失败时保留 Web fallback。宽屏继续使用现有 Web 侧栏。

`web/scripts/build-haptics.ps1` 构建包含现有页面与原生底栏的完整测试 APK，使用 `com.stuassistant.app.haptics` 和本机调试签名，可与正式 App 共存。构建入口为 `assembleHaptics :app:testDebugUnitTest`；AGP 9 默认只为 tested build type 生成单测任务，不能继续假定存在 `testHapticsUnitTest`。Windows 中文工作区通过临时 ASCII 盘符构建。
