# 首页消息测试包

测试包基于当前 1.1.6 主线，包名为 `com.stuassistant.app.haptics`，桌面名称「STU 事项助手 · 测试」。它与正式版并存，数据相互独立，版本名为 `1.1.6-native.1`；这不是正式版本发布。

安装后可在欢迎页选「先看看示例」，进入「我的」点击顶部「预览首页消息」。App 会返回「今天」并展示来信，随机播放一款表情。可以反复预览，并到「我的」切换浅色／深色和六种主题进行检查。关闭、下次再说、系统返回、GitHub 按钮都使用正式弹窗的实际实现。

预览入口仅出现在 Haptics 验证包，使用随包提供的示例，不请求服务器、不写已读记录；正式包没有这个入口，也不携带预览 JSON。真正的服务器消息仍由 API 配置控制，不把本地预览当作服务器已经上线的证据。

源码合入和服务器部署是两件事。服务器作者按照 [维护者操作手册](首页消息-服务器维护者操作手册.md) 部署后，首页自动消息才会使用新接口。

构建：在干净的已提交源码上运行 `pwsh -File deploy/make-native-release.ps1 -Variant Haptics`。脚本验证包名、版本、服务器地址及源码一致性，输出 APK 和包含 SHA-256／源码提交的 JSON 回执。修改默认消息时，同步 `backend/app/announcements.example.json` 与 `web/android/app/src/haptics/assets/announcement-preview.json`。

卡片和特效按显示时钟插值，高刷时长不变。120／144Hz 真机帧率仍需设备测试；模拟时钟验证不代表实际渲染 FPS。
