日期：2026-10-30。基线为 `web/src` 的实际页面、模型与动作。下列 54 项已完成 Compose 代码迁移；“已迁移”不表示 54 项都已在设备上逐项验收。实现文件、已运行证据和待验收项目见 [Compose 原生迁移 V1 实现与验收](Compose原生迁移V1实现与验收.md)。

首版固定五个入口：**今天／课表／事项／校园／我的**。唯一信息架构调整是合并原“计划”和“学业”的作业列表；事项保留 **待办／考试／成绩**，待办支持 **全部／个人／作业** 筛选。
考试、成绩均留在事项，不迁入课表或我的。其余页面的结构、字段与主动作按现有 JS 等价移植；不在本表扩展新首页、图表、编辑器或导航方案。

## 数据语义约束

- 学校作业的完成是本机、按用户隔离的标记，不是学校端提交；学校返回的 `schoolStatus` 独立保留。依据：`web/src/lib/store.tsx:103`、`:321`，`web/src/screens/Study.tsx:194`、`:205`。
- 个人计划的 `done` 通过服务端 Plan API 保存；与作业本机标记使用不同身份与存储，学校同步不覆盖个人计划。依据：`web/src/lib/plan-api.ts:4`、`:80`。
- Plan 的 `date/start/end` 表示安排日与安排时间；Task 的 `dueMs/dueRaw` 表示学校截止。合并展示不得把安排日冒充截止，也不得给无时间事项虚构时长。
- `none` 表示无可解析截止；`overdue` 表示已过截止；`expired` 是超过截止 14 天的历史降噪分类，不表示学校撤销任务。依据：`web/src/lib/records.ts:72`、`:80`。
- 截止优先读取有效 `dueMs`，无时区字符串按上海时间解释，未知值保留原文。考试时间、成绩、通知发布时间也保留原文与未知状态。依据：`web/src/lib/records.ts:34`、`:92`、`:131`、`:203`。
- JS 基线个人计划页没有离线缓存或离线写入队列；原生目前会随账号加密缓存回显已读取的计划快照，但无离线写入队列，写入仍须服务端确认。免登录预览只显示日期与登录提示，不承诺保存。依据：`web/src/screens/Plan.tsx:74`、`:93`、`:232`，`NativeStore.kt` 的 `commit`。
- `planApi.update` 存在，但当前 Plan 页面只调用 list/create/toggle/remove/reorder，没有完整编辑入口；首版不把新增编辑当作缺失回归。依据：`web/src/lib/plan-api.ts:75`，`web/src/screens/Plan.tsx:82`、`:115`、`:129`、`:148`、`:162`。
