# 真理钟原生开屏与外观同步

更新日期：2026-11-17。此次源码基于上游 `main` 的 `2c50fb8` 整理，保留已有首页消息、原生页面和设置逻辑。变更覆盖 Android 开屏、桌面入口、相关资源及设备测试；Web 业务和服务端不变。本次准备源码提交，沿用上游产品版本 `1.1.7 / code63`，不据此宣称正式 APK 或生产服务已发布。

## 使用者可见的变化

- 启动时先显示完整的真理钟，再以轻微蓄力、柔雾圆形揭幕和雕塑淡出来承接业务页面。
- 开屏采用两套固定舞台色：浅色白瓷 `#E8E8EA` 与深色黑曜 `#0E0E0F`。应用内六种配色继续控制业务页面，开屏舞台只随浅深外观变化。
- 设置中的“跟随系统／浅色／深色”控制桌面图标。图标切换在 Activity 停止时提交，先启用目标入口，再禁用其他入口。
- **开屏动画不阻挡操作**：已就绪的业务页面在动画期间保持可操作，覆盖层不消费触摸，不增加等待动画完成的交互门槛。
- 系统关闭动画后，页面就绪时跳过揭幕过程。

## Android 兼容范围

| 系统版本 | 系统启动画面（StartingWindow） | Compose 页面与揭幕 |
| --- | --- | --- |
| Android 13 及以上（API 33+） | 应用观察到外观选择后，通过系统 API 持久化下一次启动的浅深主题 | 使用 AGSL 柔雾揭幕；业务页面按应用设置显示 |
| Android 12／12L（API 31–32） | 同样支持持久化下一次启动的浅深主题 | 使用普通绘制的圆形遮幕降级；雕塑支持系统模糊 |
| Android 7–11（API 24–30） | 跟随系统浅深模式；不保证匹配应用内固定的相反外观 | 业务页面和揭幕采用应用外观，使用普通绘制，略过系统模糊 |

Android 7–11 的启动画面可能先跟随系统，再切换到应用外观，例如系统浅色、应用固定深色时出现一次颜色变化。此行为是接受的兼容性降级，不影响页面功能。应用首次运行、旧版本升级后的首次启动或旧数据迁移期间，系统可能仍使用此前保存的开屏主题；进程中的同步只能影响后续启动。

`activity-alias` 用于选择桌面图标，不负责覆盖目标 Activity 的主题。固定开屏主题依靠 API 31+ 的 `setSplashScreenTheme()`。已有版本持久化过的 18 个调色板主题名称保留为兼容样式，统一指向新的跟随系统／浅色／深色开屏主题，避免升级后引用失效。

## 实现与资源

- `NativeActivity.kt` 安装系统 SplashScreen，并将退出层直接移除；`SundialLaunchState` 负责等待存储就绪与揭幕进度。业务首页消息、更新提示及原有导航继续挂载。
- `LauncherThemeSync.kt` 同步 API 31+ 的系统开屏主题，并在 `onStop()`（排除配置重建）切换唯一桌面别名。
- `SundialLaunchOverlay.kt` 使用约 350ms 蓄力与 820ms 揭幕。帧间隔上限为 24ms，避免一次长帧直接跳过大量进度；实际总时长、帧率与流畅度仍取决于设备、负载及就绪时间，不承诺固定 120Hz。
- API 33+ 的 Shader 使用目标色彩空间中的舞台色和 12 次采样柔化；旧系统使用绘制降级。动画完成后卸载覆盖层与揭幕效果。
- 系统图标位图为 288dp，中心透明雕塑为 176dp；xxhdpi 使用 864／528px，xxxhdpi 使用 1152／704px。两端使用同源雕塑减少交接差异，不把单个样本的像素比较推广为所有设备都无差异。
- 三个桌面别名共用 `NativeActivity`。五个独立机型探针源集移除这些别名，保留自己的单一入口。页面内 `NativeLogo` 的浅深徽标资源保持。

## 测试与复现

`NativePackagingInstrumentedTest` 检查实际安装包的唯一启用入口、别名目标、服务地址与资源排除规则；逐一切换 `system → light → dark → system` 并核对解析结果。测试仅运行于 `.gpuqa` 包，结束时恢复原始组件启用状态，不改写用户外观偏好。

`NativeLaunchAppearanceInstrumentedTest` 检查系统浅深模式与应用三种外观的主题解析、旧样式名称兼容，以及 Activity 重建后窗口背景仍匹配业务页面。`SundialLaunchCurveTest` 覆盖曲线单调性、帧间隔钳制、蓄力释放与别名映射。

从 `web/android/` 执行：

```powershell
./gradlew.bat validateNativeConfiguration :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest :app:assembleHaptics :app:lintVitalHaptics :app:lintVitalRelease --console=plain
./gradlew.bat :app:connectedDebugAndroidTest '-Pandroid.testInstrumentationRunnerArguments.class=com.stuassistant.app.nativeapp.NativePackagingInstrumentedTest,com.stuassistant.app.nativeapp.NativeLaunchAppearanceInstrumentedTest' --console=plain
```
